## SOLUCION
El mejor método para encontrar archivos ocultos dentro de otros archivos es[`binwalk`](https://tools.kali.org/forensics/binwalk)

Si realizamos el proceso, `binwalk "Forensics is fun.pptm"`veremos que hay un montón de [`.zip`](https://en.wikipedia.org/wiki/ZIP_\(file_format\))archivos. Podemos extraerlos usando `binwalk -e "Forensics is fun.pptm"`( `-e`o `--extract`para extraer).

Ahora hay `_Forensics is fun.pptm.extracted`una carpeta a la que accederé usando [7zip](https://www.7-zip.org/) .

Como había demasiadas cosas, `0.zip`decidí automatizar el proceso de búsqueda. Las extraje `0.zip`y luego navegué hasta ellas en la terminal.

El resto fue muy incierto, intenté `grep -r pico`(buscar recursivamente) cosas como "pico" o "{" pero nada funcionó. Intenté `find -D tree|grep flag`con la esperanza de encontrar un archivo de bandera, lo cual tampoco funcionó. Finalmente, después de algunas conjeturas, intenté `find -D tree|grep hidden`lo que devolvió:

```
./ppt/slideMasters/hidden
```

Navegar a `cat ./ppt/slideMasters/hidden`:

```
Z m x h Z z o g c G l j b 0 N U R n t E M W R f d V 9 r b j B 3 X 3 B w d H N f c l 9 6 M X A 1 f Q
```

Esto no parece ningún tipo de cifrado por sustitución, podría ser base 64, así que vale la pena intentarlo.

Primero deberíamos escribir un script para eliminar los espacios:

```
s = "Z m x h Z z o g c G l j b 0 N U R n t E M W R f d V 9 r b j B 3 X 3 B w d H N f c l 9 6 M X A 1 f Q"
s = s.split(" ")
print("".join(s))
```

Esto nos dio "ZmxhZzogcGljb0NURntEMWRfdV9rbjB3X3BwdHNfcl96MXA1fQ", que luego podemos decodificar usando [este sitio web.](https://www.base64decode.org/)
